## What to check in a review

A review is not a rubber stamp. For each page, before setting `review_status = human_reviewed`:

1. **Severity against the source.** Does each pair's severity match what the cited study or monograph says? Downgrading a severe pair to mild is a safety error, not a style choice.
2. **Dosage ranges against the source.** The published range, the units, and the form (dry herb, extract, tea) must match what the citation supports.
3. **Pregnancy and nursing flags.** “Unknown — not enough data” is the correct answer when the source is silent. Do not upgrade it to “safe”.
4. **Citations still resolve.** Open every link. A dead PubMed ID is a broken citation, not a footnote.
5. **No unsourced addition.** If a claim has no source on the page, it does not belong in the review.
6. **Record it.** `review_status`, `reviewed_by_name` (a person, never a script), `reviewed_on` (YYYY-MM-DD), and what changed in `review_notes`.

Pages that were reviewed once and then edited must be set back to `needs_re_review`; the badge disappears until someone reads it again.
